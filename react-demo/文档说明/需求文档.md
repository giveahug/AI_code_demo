### 项目要求

**1. 技术栈（严格按照以下版本范围）**

- React 18（使用函数式组件 + Hooks）
- Vite + TypeScript
- React Router v6.4+
- Axios
- Ant Design 5.x（必须使用）
- @ant-design/icons
- 不使用 Redux，先使用 Context API 做简单全局状态管理

**2. 项目功能（必须包含以下页面）**

- 登录页（Login）
- 后台布局（含左侧菜单、顶部 Header、面包屑）
- 仪表盘（Dashboard）
- 用户管理（列表、分页、搜索、新增、编辑、删除）
- 角色管理（简单列表 + CRUD）
- 个人中心（简单展示用户信息）

**3. 核心学习特性要求**

- 所有页面使用函数式组件 + Hooks
- 使用受控组件处理表单
- 正确使用 useState、useEffect、useContext、useCallback
- 路由使用 React Router v6（嵌套路由 + Outlet + 受保护路由）
- Axios 请求封装 + 请求拦截器（token） + 响应拦截器（401 跳转登录）
- Antd Table、Form、Modal、Card 等组件的规范使用

**4. 后端接口约定**

- 所有接口前缀 `/api`
- 统一返回格式：
  
  ```json
  {
  "code": 200,
  "message": "success",
  "data": {},
  "total": 0   // 分页时使用
  }
  ```
- 主要接口：
  - POST /api/auth/login
  - GET /api/currentUser
  - GET /api/users (支持 page, size, keyword)
  - POST /api/users
  - PUT /api/users/{id}
  - DELETE /api/users/{id}
  - 角色类似接口
