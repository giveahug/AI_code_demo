# Admin Pro 项目目录结构说明书

本项目采用标准的 React 18 + Vite 开发规范，遵循高内聚低耦合的组件化原则。以下为项目的核心目录结构及对应说明。

```text
├── src/                      # 源代码存放主目录
│   ├── components/           # 全局可复用组件
│   │   ├── AuthRoute.tsx     # 路由鉴权守卫（验证 Token，拦截未登录访问）
│   │   ├── Layout/           # 全局页面布局相关组件
│   │   │   ├── AdminLayout.tsx # 后台左右布局组件（包含侧边栏菜单、顶部导航等）
│   │   │   └── AdminLayout.css # 布局专属的毛玻璃及渐变样式文件
│   │
│   ├── pages/                # 所有路由页面组件
│   │   ├── Login.tsx         # 登录页（带几何动画背景）
│   │   ├── Dashboard.tsx     # 仪表盘主页（动态统计图与卡片）
│   │   ├── User/             # 用户管理功能模块
│   │   │   ├── UserList.tsx  # 用户列表（表格展示、状态开关、气泡删除）
│   │   │   └── UserModal.tsx # 新增/编辑用户的弹窗组件（表单验证）
│   │   ├── Role/             # 角色管理模块
│   │   │   └── RoleList.tsx  # 角色列表卡片（展示角色权限并支持 CRUD）
│   │   └── Profile.tsx       # 个人中心（标签页切换、资料修改）
│   │
│   ├── router/               # React Router 路由配置中心
│   │   └── index.tsx         # 集中管理所有页面路由规则
│   │
│   ├── store/                # 全局状态管理
│   │   └── UserContext.tsx   # React Context API 实现的全局用户状态（提供 login/logout 方法）
│   │
│   ├── utils/                # 业务逻辑与工具函数库
│   │   ├── auth.ts           # Token 与用户信息的 `localStorage` 存取方法
│   │   └── request.ts        # 基于 Axios 二次封装的网络请求拦截器（配置 Headers 和全局报错提示）
│   │
│   ├── mocks/                # 本地离线环境核心逻辑
│   │   ├── db.ts             # 使用 localStorage 模拟后端的本地数据库（实现数据持久化）
│   │   └── adapter.ts        # Axios 自定义适配器（拦截 `/api` 请求，模拟真实的网络响应与延迟）
│   │
│   ├── types/                # 全局 TypeScript 接口声明
│   │   └── index.ts          # 存放 `User`、`Role` 等数据结构
│   │
│   ├── App.tsx               # 根组件（挂载了全局主题 ConfigProvider、UserProvider 和 Router）
│   ├── main.tsx              # React 应用入口文件
│   └── index.css             # 全局核心 CSS（重置样式与滚动条美化）
│
├── 文档说明/                  # 项目文档存放目录
│   ├── 需求文档.md           # 初始系统开发需求描述
│   ├── 使用说明书.md         # 项目的安装、启动指引及各功能演示说明
│   └── 项目目录说明书.md     # 本文档（解析项目文件构成）
│
├── public/                   # 静态资源存放目录（不会经过 Vite 处理）
├── package.json              # 项目核心配置文件（依赖列表、运行脚本配置）
├── tsconfig.json             # TypeScript 全局配置
├── tsconfig.node.json        # Vite 构建时的 TS 配置
├── vite.config.ts            # Vite 项目打包配置
└── index.html                # 单页应用基础 HTML 宿主
```

### 💡 进阶开发指南：

1. **我该如何增加新的业务模块？**
   在编写新功能时，通常只需要在 `src/pages/` 中建立新文件夹与组件，并在 `src/router/index.tsx` 添加路由映射，同时修改 `src/components/Layout/AdminLayout.tsx` 里的左侧菜单 `menuItems` 即可。

2. **如何移除 Mock，接入真实的后端 API？**
   目前本项目通过前端适配器完全拦截了 `/api` 请求。如果您完成了后端开发，只需打开 `src/utils/request.ts` 并**移除或注释掉**以下这行代码：
   ```typescript
   setupMockAdapter(request);
   ```
   然后调整 `baseURL`（例如改为 `http://localhost:8080/api`），所有的请求就会自然无缝地打入您的真实服务器！
